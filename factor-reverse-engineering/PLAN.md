# 因子逆向工程 — 验证方案

## 目标
从历史暴涨币的链上特征中，反推可量化的因子，用于扫描当前币种。

## 第一阶段：小样本验证（先跑通再说）

### 选币

**成功组（2024-2025 大牛币，币安已上线）**
| 币 | 逻辑 |
|----|------|
| TAO | AI龙头，底部到高点100x+ |
| RENDER | DePIN+AI，迁移Solana后暴涨 |
| WIF | Meme代表 |
| FET | AI概念 |
| PENDLE | DeFi创新，TVL激增 |
| BONK | Solana meme |
| SEI | 新公链 |

**对照组（同期上线但没暴涨的）**
从币安2024上线的币中随机选5-7个做对照

### 数据源（全部免费）

| 指标 | 数据源 | 获取方式 |
|------|--------|---------|
| TVL 历史 | DeFiLlama API | GET /v2/chains/{chain} |
| 代币价格 | Binance API | 已有 |
| 交易量 | Binance API | 已有 |
| 社交热度 | 待定（LunarCrush免费层/Dune） | - |

**链上数据（免费但需要配置）：**
| 指标 | 数据源 |
|------|--------|
| 日活地址数 | Dune Analytics（SQL查询） |
| 交易所净流入/流出 | Dune / Nansen免费层 |
| 持币地址数增长 | 各链浏览器API（Etherscan/Solscan） |

### 时间窗口

对每个成功币：
- 取暴涨启动前 **30天、60天、90天** 三个时间点的快照
- 对照同期大盘（BTC）表现排除普涨因素

### 分析维度

1. **TVL 加速度**：暴涨前TVL是否加速增长（二阶导>0）
2. **地址增量**：新地址日增量是否走高
3. **交易所持仓比**：CEX余额占总供应比是否在下降（=用户提到链上）
4. **相对大盘强度**：BTC下跌时该币是否抗跌（相对强弱）
5. **社交流量**：Twitter/Reddit提及量是否有爆发

### 输出

每一个指标，输出：
- 成功组均值 vs 对照组均值
- T检验显著性
- 是否可作为候选因子

## 第二阶段：因子化（验证通过后才做）

- 将显著因子加权合成评分
- 在历史数据上做滚动回测
- 确定最优参数

## 执行计划

1. 先用 DeFiLlama + Binance 拉 TVL + 价格数据（这两个最快）
2. 再做链上地址数据（需要Dune SQL/浏览器API）
3. 最后做社交数据
4. 输出统计报告
